# MILO CASHIER 3.5.0 — طباعة Python بدل صفحات المتصفح

هذا الإصدار يحافظ على موقع MILO CASHIER وGoogle Sheets، ويضيف **خدمة طباعة محلية على ويندوز** باستخدام Python وESC/POS. لا تحتاج Electron أو npm.

## إعداد الخدمة على ويندوز

1. ثبّت Python 3.11 أو أحدث من python.org، وحدد Add Python to PATH عند التثبيت.
2. من CMD داخل مجلد `python_print` شغّل:

   `py -3 -m pip install -r requirements.txt`

3. شغّل `py -3 printer_server.py` مرة واحدة، سيُنشئ ملف `printer_config.json` ويطبع أسماء طابعات ويندوز المتاحة.
4. افتح `printer_config.json` بمحرر نصوص واضبط `printer_name` **مطابقًا تمامًا** لاسم طابعة الفواتير في ويندوز، وأضف **رابط موقع الكاشير الأصلي** إلى `allowed_origins` (مثال `https://yourname.github.io` بدون شرطة مائلة ختامية). احتفظ برمز `token` كما هو.
5. أعد تشغيل `py -3 printer_server.py`، واترك النافذة مفتوحة أثناء تشغيل الكاشير.
6. ارفع ملفات **الموقع** من المجلد الرئيسي (وليس ملفات python_print) لاستضافة HTTPS، وافتح الموقع في Edge أو Chrome.
7. من الإعدادات ← الطباعة والفاتورة: اختر «Python مباشر»، وألصق `token`، واحفظ. ثم اضغط زر «اختبار اتصال Python» من صفحة الإعدادات.

## السلوك

- فاتورة زبون: صورة حروف عربية/أرقام وأصناف وQR تُرسل على **شرائح ESC/POS متتابعة في مهمة RAW واحدة** ويتبعها أمر قص واحد.
- وضع المطعم: مهمتان RAW منفصلتان، واحدة للزبون والأخرى للمطبخ، وبنفس رقم الطلب.
- لا نافذة Print ولا عناوين مواقع المتصفح ولا مقياس صفحة ثابت.
- عند تعطل Python **لا يتم التحول تلقائيًا لطباعة المتصفح** لتجنب طباعة الفاتورة مرتين. يمكن إعادة طباعتها من السجل بعد علاج المشكلة.
- تقارير إغلاق الوردية وبعض المستندات تبقى على طباعة المتصفح حاليًا؛ الطباعة المباشرة تشمل فواتير البيع والمطبخ.

## متطلبات وتوافق

- الطابعة **يجب أن تدعم ESC/POS** وأوامر الصور النقطية `GS v 0` وأمر القص `GS V`.
- تصلح طابعات USB المعرفة في ويندوز إذا كان تعريفها يقبل مهام RAW بدون تغيير البيانات؛ بعض تعريفات GDI لا تدعم ذلك.
- الخدمة تعمل على `127.0.0.1` فقط وتستخدم رمزًا سريًا `token` وعمليات CORS لأصول محددة. لا تفتح المنفذ للإنترنت أو تغيّر عنوان الاستماع إلى `0.0.0.0`.
- متصفح HTTPS قد يقيّد الاتصال بالخدمة المحلية بسبب سياسات أمان الشبكة المحلية. لو فشل الاختبار، تحقق من سماح Edge/Chrome بالوصول إلى الأجهزة المحلية. قد يلزم جسر HTTPS محلي بتوثيق صالح أو تطبيق محلي عند بعض إعدادات المتصفح.
- الطباعة لا تتحقق من حفظ الفواتير في Google Sheets؛ يعتمد التأكيد على منطق الكاشير الحالي. لا يشير نجاح HTTP إلى خروج الورق فعليًا.
- لا ينشئ QR ضريبي إلا عند وجود رقم ضريبي سعودي مناسب؛ لا يضمن هذا وحده الامتثال للوائح الفوترة الإلكترونية.

## فحص وتشخيص

في مجلد `python_print` شغّل `py -3 printer_server.py`. عند الطباعة يظهر خطأ الخدمة في CMD، وإذا لم تجد الطابعة تحقق من `printer_name`. جرب أولًا فاتورة صغيرة ووردية اختبار على بيانات غير إنتاجية.

## ملاحظة عن الإصدار

نسخة المصدر مبنية على **3.4.8**. يجب اختبار طباعة Python على جهازك؛ لا يمكن التحقق من طابعة حرارية فعلية داخل بيئة إنشاء الملف.
